# C Habit Tracker

A simple command-line Habit Tracker built using the C programming language.

## Features

- Add new habits
- View all saved habits
- Mark habits as completed
- Save habits to a text file
- Load saved habits when the program starts

## Technologies Used

- C Programming
- File Handling
- Structures
- Functions
- Loops and Switch Statements

## How to Run

1. Download or clone this repository.
2. Make sure you have a C compiler installed, such as GCC.
3. Open a terminal in the project folder.
4. Compile the program:

   gcc habit_tracker.c -o habit_tracker

5. Run the program:

   On Windows:

   habit_tracker.exe

   On Linux or macOS:

   ./habit_tracker

## How to Use

1. Choose option 1 to add a habit.
2. Choose option 2 to view your habits.
3. Choose option 3 to mark a habit as completed.
4. Choose option 4 to save and exit.

## Data Storage

Habits are stored in a local text file named `habits.txt`.
